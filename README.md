# DTS Hub board assets

Public files for DTS Hub boards (images, flyers, PDFs). Hub needs a direct **HTTPS** URL to each file.

## Add a file

1. Drop it under `boards/<agency-or-board-name>/`.
2. Commit and push to `main`.
3. Paste this URL into Hub (replace the path):

```
https://raw.githubusercontent.com/sevans5714/dts-hub-board-assets/main/boards/<folder>/<filename>
```
